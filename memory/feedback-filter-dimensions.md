# 筛选数据维度：必须让用户设阈值

**规则**：搜索达人得到结果后，在二次筛选时，必须把数据维度（粉丝数、场均观看、场均销售额等）列出来让用户多选并设定阈值范围，不能自行决定筛值。

**Why**：用户明确强调——数据维度的筛选阈值是业务决策，不同时期推不同量级的达人，用户比我更清楚。

**How to apply**：
- 搜索结果出来后，展示摘要和可筛选的数据维度
- 让用户多选要启用的维度 + 设定各维度的 min/max 范围
- 常用维度：粉丝数、场均观看、场均销售额、城市、直播频次
- 展示筛选后还剩多少人，用户确认后再进入邀约流程
- 用户说「不筛了全部用」时跳过此步
