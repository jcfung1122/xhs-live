## API 能拿到什么？跟你现在用的有什么区别？

你现在日常筛选只看三个数：**粉丝 ≥5万、场均观看 ≥5k、场均销售 ≥1万**。

但 API 实际返回了 3 组完整数据，远超你现在用的范围：

| 数据组 | 你现在用 | API 实际返回（你没用的） |
|--------|---------|----------------------|
| **基础** | 粉丝数 | ✅ |
| **直播数据** | 场均观看、场均销售 | 下单率、活跃率、客单价、GPM、最高在线、中位观看 |
| **品类数据** | — | 她卖过什么品类、每个品类卖了多少钱、均价多少 |
| **粉丝画像** | — | 地域分布、年龄分布、兴趣偏好、消费力 |
| **合作数据** | — | 合作过多少商家、参考佣金率、商品数 |
| **邀约状态** | — | permission_type（可邀约/已发送/被拒） |

## 一、达人筛选更精准（同样 50 条配额，发给更优质的人）

### 新增 4 个筛选维度

| 维度 | 示例达人的值 | 怎么用 | 建议阈值 |
|------|-----------|--------|---------|
| **下单粉丝率** `proportion_of_order_fans` | 56.5% | 粉丝里下单的比例。太低 = 粉丝只看不买，发邀约也没用 | ≥20% |
| **活跃粉丝率** `proportion_of_active_fans` | 82.2% | 活跃粉丝占比。太低 = 僵尸粉多，挂链接没人点 | ≥50% |
| **客单价** `fan_unit_price` | 4,007 元 | 粉丝平均消费金额。跟你的产品价格比，差太远不合适 | 500~5000 元 |
| **GPM** `live_gpm` | 17,165 | 千次观看成交额。衡量达人带货效率的核心指标，越高说明越能卖 | ≥5,000 |

### 实际效果

- **不加这些维度**：每天 50 条配额，发给所有筛选通过的人。其中可能有活跃率 30%、下单率 5% 的"假流量"达人——发了也不转化。
- **加了这些维度**：同样 50 条，发给你知道"粉丝活跃且愿意花钱"的达人。

## 二、判断产品是否匹配（发了会不会白费）

API 返回了她的**带货品类 + 每个品类的实际销售额和均价**：

### 示例达人带货品类（示例）

| 品类 | 销售额 | 均价 | 跟 你的品牌 匹配？ |
|------|--------|------|-------------|
| 西装 | 24.6 万 | 2,243 元 | 价位偏高但接近 ✅ |
| 真丝上装 | 23 万 | 1,397 元 | 完美匹配 ✅ |
| **毛针织衫** | 108 万 | 1,145 元 | **核心价格带 你的价格带 元** ✅ |
| 裤子 | 53 万 | 1,107 元 | 完美匹配 ✅ |
| 衬衫 | 55 万 | 994 元 | 完美匹配 ✅ |
| T恤 | 22 万 | 398 元 | 偏低 ⚠️ |
| 定制珠宝 | 17 万 | 8,782 元 | 太高 ❌ |

**你的品牌产品价格**: 768-1,099 元，刚好落在她核心价格带。

### 反向例子

假设另一个达人场均销售也很高，但品类全是 50 元 T恤、30 元袜子：
- 客单价极低 → 她的粉丝习惯买便宜货
- 你的 768 元包发给她的粉丝 → 转化率会很低
- **结论**：这个达人数据再好看也不适合你

**以前**你只能在邀约后凭经验判断，**现在**发邀约前就能判断产品是不是匹配。

## 三、佣金策略更聪明

API 返回了平台的**参考佣金率**：女装类目 **15%**。

| 对比 | 平台同行 | 你给的 | 差距 |
|------|---------|--------|------|
| 佣金率 | 15% | 30-40% | 你的佣金是别人的 **2~3 倍** |

### 怎么用

在邀约留言里可以明确写出对比，增强吸引力：

> "纯佣合作，佣金 30-40%（同行普遍 15%，我们是 2-3 倍）"

这比单纯说"30-40% 佣金"更有说服力——因为达人能看到"你比别人多给多少"。

## 五、邀约状态追踪（避免浪费配额）

API 返回 `permission_type`，告诉你这个达人当前能不能邀约：

| permission_type | 含义 | 你应该怎么做 |
|-----------------|------|------------|
| **0** | 可邀约，没发过 | ✅ 发 |
| **2** | 已发送，等待达人响应 | ⏳ 等几天，不要重复发 |
| **其他** | 被拒 / 过期 / 黑名单 | ❌ 跳过或等窗口期过 |

**示例达人当前是 `2`**，意味着你 6/22 发了她还没回应。这时候再发一条会浪费一条配额。

### 现在 vs 以后

| | 现在 | 用了 API 数据后 |
|------|------|---------|
| 判断能不能发 | 靠数据库去重（同一个人只发一次） | 平台直接告诉你 permission_type |
| 重复浪费 | 可能发了同一个人多次（昵称变了查不到） | 直接跳过 |
| 重试时机 | 7 天后手动重试 SKIP | 看 permission_type 判断是否已过期，精确重试 |

## 六、整体效率提升对比

| 环节 | 现在 | 加入 API 数据后 | 效率提升 |
|------|------|---------------|---------|
| **筛选** | 粉丝+观看+销售 3 个维度 | 加下单率+活跃率+客单价+GPM 共 7 个维度 | 同样 50 条邀约，发给更可能成交的人 |
| **匹配判断** | 凭经验（她卖女装的，应该合适） | 看实际品类+均价+客单价，量化匹配 | 减少"卖了但不成交"的浪费 |
| **佣金说服** | "佣金 30-40%" | "佣金 30-40%（同行 15%）" | 达人接受率可能更高 |
| **粉丝判断** | 不知道她粉丝是谁 | 地域+年龄+兴趣画像 | 避免"粉丝不对路"的无效合作 |
| **去重** | 按昵称去重（可能漏） | 按 distributor_id + permission_type 精确去重 | 减少重复邀约浪费 |
| **重试** | 7 天固定窗口 | 看 permission_type 是否真正过期 | 不浪费重试额度 |

## 七、建议落地的优先级

| 优先级 | 做什么 | 收益 |
|--------|--------|------|
| **P0（现在就做）** | 筛选时加入活跃粉丝率 ≥50%、下单率 ≥20% | 不费额外配额，提高成交概率 |
| **P1（本周末）** | 邀约留言里加入佣金对比（"同行 15%，我们 30-40%"） | 提高接受率 |
| **P2（下周）** | 筛选时加入客单价匹配（500-5000） | 减少产品不匹配的浪费 |
| **P3（后续）** | 按粉丝画像自动匹配 你的品牌 目标客群 | 最精准但需要先积累数据 |
