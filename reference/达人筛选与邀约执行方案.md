# 达人筛选与邀约 · 执行方案

> v1.0 · 2026-06-23

---

## 一、筛选标准（搜索后执行）

搜索到达人后，按以下 7 个维度过滤，全满足才进入邀约名单：

| # | 维度 | 规则 | 值 |
|---|------|------|-----|
| 1 | 粉丝数 | ≥ 下限 | 50,000 |
| 2 | 场均观看 | ≥ 下限 | 5,000 |
| 3 | 场均销售额 | ≥ 下限 | 10,000 元 |
| 4 | 活跃粉丝率 | ≥ 下限 | 50% |
| 5 | 下单粉丝率 | ≥ 下限 | 20% |
| 6 | 客单价 | 在范围内 | 500 ~ 5,000 元 |
| 7 | GPM | ≥ 下限 | 5,000 |

**备注**：
- 维度 1~3 已在用，维度 4~7 新增。
- 活跃粉丝率、下单粉丝率、客单价、GPM 来自 API `get_user_detail` 接口。
- API 无数据时（达人未开过直播），只检查 1~6，GPM 跳过。

---

## 二、达人详情必查（邀约前）

对每个筛选通过的达人，调用 `get_user_detail` 接口获取完整数据，必查项：

| 查什么 | 字段 | 判断 |
|--------|------|------|
| 下单粉丝率 | `proportion_of_order_fans` | < 20% → 跳过 |
| 活跃粉丝率 | `proportion_of_active_fans` | < 50% → 跳过 |
| 客单价 | `fan_unit_price` | 不在 500~5000 → 跳过 |
| GPM | `live_gpm` | < 5000 → 跳过 |
| 带货品类 | 来自 `get_user_cooperation` | 跟 你的品牌产品价格带（你的价格带）差太远 → 标记降级 |

---

## 三、邀约前确认清单

每次批量邀约前，向用户展示：

1. **达人名单**：序号 + 昵称 + 粉丝数 + 下单率 + 客单价
2. **邀约留言**：固定模板（见第四节）
3. **佣金**：30%（lower）/ 40%（higher）
4. **总人数 + 预计耗时**

用户确认后才执行。
