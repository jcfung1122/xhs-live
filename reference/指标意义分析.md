## 一、GPM 详解

### 1.1 GPM 是什么？

**GPM = GMV Per Mille**，中文叫「千次观看成交额」。

```
GPM = (直播间总成交额 / 总观看次数) × 1000
```

**大白话**：这个达人每吸引 1000 个人来看直播，能卖出多少钱的货。

### 1.2 GPM 的实际含义

| GPM 高低 | 代表了什么 |
|----------|-----------|
| **GPM 高** | 流量变现能力强。每千次观看能产生高销售额。要么转化率高，要么客单价高，要么两者都强。 |
| **GPM 低** | 流量变现能力弱。虽然有人看，但转化不行，或者卖的东西太便宜，总销售额上不去。 |

### 1.3 为什么阈值设在 < 5000？

> 每千次观看产生 < 5000 元成交 → 判定为「GPM低」

**推算逻辑**：

一场直播假设：
- 场均 10,000 次观看
- GPM = 5,000 → 成交额 = 5,000 × 10 = 50,000 元
- GPM = 2,000 → 成交额 = 2,000 × 10 = 20,000 元

你的品牌 的包单价 768~1,099 元，假设场均 10,000 观看、转化率 2%（200 人下单）、客单价 900 元：
- 理想 GMV = 200 × 900 = 180,000 元
- 理想 GPM = 180,000 / 10 = **18,000**

所以 GPM < 5,000 意味着：要么转化率很低，要么卖不动高价品，要么流量质量差。这类达人对 你的品牌 来说 ROI 偏低。

### 1.4 GPM 高不代表客单价高

反直觉的一点：**GPM 高不一定客单价高，GPM 低不一定客单价低**。

| 组合 | 案例 | 含义 |
|------|------|------|
| 高客单价 + 高GPM | Charlene（客单¥7,486, GPM¥37,733） | 卖得贵 + 转化还好 → 顶级达人 |
| 高客单价 + 低GPM | 张小玩（客单¥3,938, GPM¥3,848） | 客单价不低但转化偏低 |
| 低客单价 + 高GPM | 几乎不存在（低价品要达到高GPM需要极高转化） | — |
| 低客单价 + 低GPM | 张总源头工厂店（客单¥1,721, GPM¥576） | 卖便宜货 + 转化也没拉起来 |

结论：**GPM 是效率指标，反映的是「流量 × 转化 × 单价」的综合结果**，不能单独用 GPM 反推任何一个单一维度。

## 二、四个指标的关系网

```
                    ┌──────────────┐
                    │   粉丝总数    │
                    └──────┬───────┘
                           │
              ┌────────────┼────────────┐
              ▼            ▼            ▼
      ┌──────────┐  ┌──────────┐  ┌──────────┐
      │活跃粉丝率 │  │下单粉丝率 │  │  客单价   │
      │(质量)    │  │(信任度)  │  │(消费力)  │
      └────┬─────┘  └────┬─────┘  └────┬─────┘
           │             │             │
           │             └──────┬──────┘
           │                    ▼
           │            ┌──────────────┐
           └───────────►│   GPM        │
                        │ (综合效率)    │
                        └──────────────┘
```

### 2.1 活跃粉丝率（≥ 50%）

**含义**：粉丝中有多少是活跃用户（近期登录/互动过的）。

**为什么重要**：
- 活跃粉丝率低 → 大量僵尸粉/沉默粉 → 直播推送触达率低 → 直播间没人来
- 小红书算法推流优先给活跃粉丝，活跃率低连第一波流量都起不来

**典型场景**：达人买粉/互粉导致粉丝虚高，活跃率可能只有 20~30%。50 万粉但活跃率 30%，实际有效粉丝只有 15 万。

### 2.2 下单粉丝率（≥ 20%）

**含义**：粉丝中下过单的比例。

**为什么重要**：
- 反映粉丝的「购买基因」——这届粉丝习惯掏钱还是习惯白嫖
- 下单率高的达人，粉丝进直播间后转化阻力小
- 跟活跃率配合看：活跃率 + 下单率双高 = 粉丝质量极好

**关联 GPM**：下单率直接影响 GPM。同样客单价 3,000 元：
- 下单率 60% → GPM 可能 12,000+
- 下单率 20% → GPM 可能只有 4,000

### 2.3 客单价（500 ~ 5,000）

**含义**：`总销售额 ÷ 下单粉丝数`，每个下单粉丝平均花多少钱。

**为什么上下限都要设**：
- **< 500 偏低**：粉丝消费力太弱，你的品牌 包 768~1,099 很难卖动
- **> 5,000 偏高**：粉丝习惯买高价品（奢侈品/大件），你的品牌 包在他们眼里「太便宜」，达人可能不愿意带低价品
- **豁免**：客单价高但实际带货价格带落在 500~2,000 → 说明达人虽然高消费粉丝多，但日常卖的货跟 你的品牌 价位匹配

**关联 GPM**：客单价是 GPM 的乘数因子之一。但**客单价高 ≠ GPM 一定高**：
- 客单价高 + 转化率低 → GPM 可能一般
- 客单价中等 + 转化率极高 → GPM 可以很高

### 2.4 GPM（≥ 5,000）

**含义**：千次观看成交额（见第一章）。

**为什么是综合性最强的指标**：
- GPM 同时含了：流量质量 × 转化意愿 × 客单价
- 它是「结果指标」——前面的活跃率、下单率、客单价都是「过程指标」
- 三个过程指标都好 → GPM 基本不会差
- 过程指标有个别偏低 → GPM 可能还能救（因为其他维度强）

## 四、当前阈值反思

| 阈值 | 设置理由 | 是否可能过严？ |
|------|----------|---------------|
| GPM ≥ 5,000 | 低于 5,000 说明变现效率不够 | 可能。如果达人客单价刚好匹配 你的品牌（~900），但 GPM 在 4,000~5,000，说明转化率~0.5%，不算特别差 |
| 活跃率 ≥ 50% | 低于 50% 说明一半粉丝是沉默的 | 相对合理 |
| 下单率 ≥ 20% | 低于 20% 说明粉丝购买意愿弱 | 相对合理 |
| 客单价 500~5,000 | 你的品牌 包 768~1,099 的适配范围 | 上限 5,000 已通过豁免规则缓解 |

**GPM 阈值敏感度分析**：

假设把 GPM 阈值从 5,000 降到 3,000：
- 今天 PENDING 中 12 个「GPM低」达人里，GPM 在 3,000~5,000 的有：饭饭饭大月(4,662)、幺幺灵(4,456)、张小玩(3,848)、Sega小希(3,784)、一只丘(3,342)、大倩倩(3,261)
- 约 6 人可能从 PENDING 变为 ✅ 优质

**要不要调？** 取决于你能接受多低的转化效率。GPM=3,000 意味着 10,000 观看只产出 30,000 销售额（~33 个包），转化率约 0.33%。

## 五、总结

1. **GPM 是最综合的效率指标**，反映流量变现能力，不是单纯的高客单价
2. **活跃率 + 下单率** 是粉丝质量的双保险，低则说明达人底子有问题
3. **客单价** 是匹配度指标，确保达人粉丝消费力跟 你的品牌 价位对齐
4. **四个指标不是孤立的**，要组合看：活跃+下单双高 + 客单价匹配 + GPM 自然高 = 最好的达人
5. **豁免规则** 修补了客单价一刀切的缺陷，核心逻辑是「看实际卖什么，不看粉丝平均消费」
